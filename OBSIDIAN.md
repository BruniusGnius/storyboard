# Obsidian Workflow

The Skill can live outside an Obsidian Vault. Store project outputs inside the Vault if desired.

Suggested project structure:

```text
Video-Project/
├── 01_Narrative/
├── 02_Creative-Direction/
├── 03_Visual-Development/
├── 04_Storyboard/
│   ├── STORYBOARD.md
│   ├── STORYBOARD_PROMPT_PACK.md
│   ├── storyboard.json
│   ├── storyboard-prompts.json
│   ├── handoff.json
│   ├── panels/
│   └── revisions/
├── 05_Technical-Shot-Plan/
└── 06_Production/
```

`STORYBOARD.md` is optimized for human review; JSON files are the machine handoff. Generated images can be linked/embedded by stable `SBxxx` ID.
