# Audiovisual Pipeline Position

## Upstream

### 1. Locution Narrative Map
Defines what the piece is doing narratively through time: timing, phrases, beats, intention, emotion, energy, subtext, and narrative arc.

### 2. Creative Direction Map
Defines the governing visual concept, human decisions, visual system, visual arc, restrictions, and Creative Direction Lock.

### 3. Visual Development
Materializes the visual world: references, moodboards, Visual Canon, character/environment/prop/technology sheets, concept frames, continuity anchors, and prompt inheritance fragments.

## This Skill — Storyboard

Answers:

**What do we see, in what order, for how long provisionally, and how does each visual unit serve the video?**

It creates `SQxx`, `SCxx`, and `SBxxx` architecture, continuity state, provisional camera for visual review, and a high-fidelity image-generation prompt for every panel.

## Downstream

### 5. Technical Shot Plan
Finalizes shot engineering: focal/T-stop, body/lens package, rig, camera movement, focus, exposure, lighting implementation, frame-accurate timing, and production/generation variables.

### 6. Generative Production
Builds final image/video prompts and generates/produces approved shot assets using canon + storyboard semantics + technical shot specifications.

### 7. Edit / Assembly
Assembles voice, shots, graphics, sound, timing, and final delivery.
