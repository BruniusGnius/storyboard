# Beat-to-Shot Translation

## Core rule

A narrative beat is a semantic unit. A storyboard shot is a visual-temporal unit. They are related but not equivalent.

## Translation questions

For each beat ask:
- What does the audience know before it?
- What must change in perception?
- What visible evidence can cause that change?
- Is a new image required?
- Can the current action continue while the voice introduces a new idea?
- Does the beat need inspection time, surprise, contrast, or an emotional reaction?

## Voice/image relationships

Classify each panel when relevant:
- `evidentiary`: image proves the statement;
- `complementary`: image adds concrete meaning;
- `counterpoint`: image creates productive tension;
- `anticipatory`: image prepares an idea before the voice states it;
- `payoff`: image resolves prior setup;
- `literal`: image directly depicts wording; use intentionally, not by default.

## Cut logic

Prefer cuts motivated by:
- new evidence;
- changed agency;
- changed point of view;
- spatial revelation;
- emotional turn;
- scale change required for comprehension;
- action completion/interruption;
- deliberate rhythmic acceleration/deceleration.

Do not cut solely because a sentence ended.

## Timing

When source timecodes exist:
- preserve beat timing as evidence;
- allocate continuous storyboard shot windows across the video;
- allow a shot to span beat boundaries;
- allow several shots inside one beat;
- use pauses as available visual time rather than automatic empty gaps.

If primary panel time windows overlap, require an explicit compositing/layer reason.
